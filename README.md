## Project Title 

#***Predicting Spotify Song Popularity Scores***

## Description 

This project was for my Business Analytics course at the University of Iowa. It was a group project where I had three other group mates working with me. The main goal of this group project was to predict the popularity scores of Spotify songs based off a Kaggle datasheet we found. Our first milestone for this project was coming up with a set of variables from the dataset we thought would be good predictors for songs popularity scores on Spotify. 

Our next segment was cleaning the dataset so it could properly be used when running analysis and interpreting the data. We cleaned the data by removing duplicates, deleting fields that did not relate to our research question, and creating dummy variables for the categorical data we needed to use in the future analysis. The next step was to figure out what testing needed to be done in order to test our research question/hypothesis. 

We decided to run multiple analysis which I was in charge of. We ran an ANOVA test with our variables to gain insight into the differences between groups. We also ran a correlation analysis to better understand if our variables were collinear, meaning there are strong associations between variables. Our final and most significant model to our project was a backward stepwise regression analysis. This is a regression form where you start off running a regression with all your variables and then take the least significant one out and run it again. We did this until all our variables were significant to predicting Spotify popularity scores of songs. Some of our final variables included the different genres of music, the tempo of music, and the duration of the song. 

We concluded our project with our findings from the previous analysis and final regression to create our understanding of what it all meant. We made a presentation in PowerPoint, explaining how all the variables interacted with one another and how they come together to be significant predictors of songs popularity scores on Spotify. Throughout this project I learned many valuable technical and soft skills that I will continue to grow as I move forward in my education and career. It helped me better understand the different analytical perspectives that need to be taken to result in good and meaningful research. 

## Tools Used 

In this project, we used Microsoft Excel to analyze our dataset. Within Excel we performed analysis with the Data Analysis ToolPaK download. We used a correlation matrix, ANOVA test, backward stepwise regression, and created residual visualizations throughout our project.
